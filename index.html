GitHub Pages 1分公開手順 ＆ 通信の仕組み解説

バックエンドサーバー不要でスマホと展示PCが直結する理由

1. GitHub Pages で学園祭用に公開する手順（3ステップ）

  1. GitHubで新規リポジトリ（例: festival-arena）を作成します。
  2. このコードを index.html という名前でリポジトリにアップロード（Commit & Push）します。
  3. リポジトリの Settings > Pages を開き、Branchを main にして Save します。

✨ これだけで https://あなたのID.github.io/festival-arena/ が公開され、画面のQRコードも自動的にそのURLに切り替わります！

2. なぜ静的サイト（GitHub Pages）だけでリアルタイム通信ができるの？

通常のオンラインゲームは中継用のWebSocketサーバーが必要ですが、本システムは WebRTC (Web Real-Time Communication) の RTCDataChannel を利用しています。

① シグナリング
QRコードのRoom IDを使い、PeerJSの無料クラウドブローカー経由でお互いのIP/経路情報(SDP/ICE)を交換
② P2P ダイレクト接続
NAT越え（STUN）を行い、来場者のスマホと展示PCのブラウザ同士が直接P2Pトンネルを確立
③ 超低遅延パケット通信
ジョイスティックの座標やボタン入力を秒間30フレームのJSONパケットとして直接送受信！

3. 学園祭当日の展示運営アドバイス

  • スマホキャリア回線でも接続可能: 来場者は会場Wi-Fiに繋ぐ手間なく、自分の4G/5G回線のままQRコードを読むだけで参加できます。
  • 人がいない時間も賑やかに: 「+AIボット」ボタンを押しておくと、AIノードが自動で戦うためデモ画面として常に華やかになります。
